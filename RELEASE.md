## Umwelt license check (2026-11-10)

- **What ships:** `scripts/ship.ps1` copies Umwelt Engine's `src/umwelt` package, unmodified, into `tools/_vendor/umwelt/` of every Windows build, and stages `LICENSE`, `LICENSE-EXCEPTION.md` and Umwelt's own `NOTICE` beside it. The exception file is copied verbatim, so its source link stays https://github.com/AQuantumArchitect/umwelt-engine.
- **The license:** Umwelt Engine (distribution name `umwelt-engine`, import name `umwelt`, github.com/AQuantumArchitect/umwelt-engine) is **AGPL-3.0-or-later**, plus an additional permission in `LICENSE-EXCEPTION.md` from copyright holder Luke Spooner. The exception lets any repository owned by the AQuantumArchitect GitHub account, including this one, link or bundle Umwelt Engine without the rest of that work becoming AGPL. Umwelt itself, and any modification of it, stays AGPL-3.0-or-later. There are no modifications; the copy is verbatim at the pinned commit.
- **Verdance's split:** Lua, data, scripts and docs stay GPL-2.0-or-later. The kernel (`tools/`, `app/`) stays all rights reserved. `LICENSE` part 2 carves `tools/_vendor/umwelt/` out of that reservation because the snapshot is Umwelt's code under Umwelt's terms. The exception is what allows the bundle.
- **The pin:** public tag `v0.2.1` (commit `ad1c4cb`). `ship.ps1` fetches that tag with no token and checks the commit after checkout. The public repository is a fresh snapshot, not a fast-forward of the private `umwelt` history.
- **Earlier development line:** the private pin through `a00a0e7` (`v0.2.0`) was Apache-2.0. Builds 0.13.0 and 0.14.0 also shipped that line without its LICENSE file. Those builds are not this pin.
