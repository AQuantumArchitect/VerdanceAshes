# Agent instructions

## Ready for a human playtest

When you judge the game ready for a release cut and a human playtest, open a GitHub issue labelled `ready-for-human-playtest`. Then wait for Luke's sign-off in that issue before any release.

The issue must include:

- the commit SHA
- the version
- how to run it: `SETUP.bat`, then `PLAY.bat`, on Windows with stock Beyond All Reason
- the evidence
- the estimated time to beat (3 hours or more)
- the known issues

## Factions

The player faction is the Ashwalkers, a messy mercenary band within the Null Mercs. Null Mercs is the umbrella faction, and it plays as Legion. There is no Clans faction. Beyond All Reason's own unit and faction identifiers stay as BAR wrote them.
