On 2026-10-20 the working tree also dropped two history dumps. Git still has every file.

| Path | What it was |
|------|-------------|
| `_attic/` | Pre-pass snapshots of kernel, gadgets, widgets, and retired player scripts |
| `outbound/` | Numbered LLM / swarm handoff briefs (`01`…`48` plus WO reports) |

```

```

Do not recreate these folders in the product tree. Operator notes belong in `docs/` or `app/bin/forge/`.
