VERDANCE'S ASHES - START HERE
=============================

The green is dying. Ashwalkers hold the line.
This is a campaign shell for Beyond All Reason (public alpha).

ONE PATH
--------
1. Install Beyond All Reason and launch it once (it installs an engine).
2. From this folder:
     SETUP.bat     (once: finds BAR, asks for the path if it cannot,
                    installs the mutator, writes mission 1)
     PLAY.bat      (every session - leave the window open)
     RESET.bat     (start the campaign over; old save kept in state\backups)
3. On the war map (http://127.0.0.1:8770):
     - Choose a green "sortie"
     - Confirm the objective (green) on the briefing table
     - Click Launch: the field loads in BAR behind the hub
     - Pick who goes, then click Drop
   The first Launch on a new map downloads that map from BAR's content
   service (about 100 MB); the hub shows the progress.
4. Play the sortie in BAR. Space dismisses the briefing.
   After a win, 1/2/3 can keep fighting on the same map.
5. When the match ends, the kernel bridge brings the result home.
   If the map does not move: After the fight - bring it home
6. Talk, rest, hire mercs, or take the next drop.

Zip build: Python is embedded under runtime\, nothing to install.
Git clone: Python 3.10+ must be installed (python.org, "Add to PATH").

IN-GAME SHORTCUTS
-----------------
  /vastory   story panel
  /vazones   print the loaded zone map (the minimap paints the company's
             BELIEF about each zone - what it thinks it holds and fears -
             not the ground truth; line of sight confirms or surprises)
  /vahelp    list commands

SENDING FEEDBACK
----------------
Hub: System menu -> Export feedback bundle
     writes export\feedback_<stamp>.zip (campaign state + kernel logs)
Attach it to an issue: https://github.com/AQuantumArchitect/VerdanceAshes/issues
Say what you did, what you expected, what happened.
