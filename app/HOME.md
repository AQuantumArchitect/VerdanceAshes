# Verdance app/

Player path is the **workspace root**, not this folder.

```
..\SETUP.bat
..\PLAY.bat
..\SHIP.bat
```

| Place | Role |
|-------|------|
| `bin/` | Player launchers (`PLAY`, `HUB_HOST`, `SHIP`, `_env`) |
| `bin/forge/` | Operator only |
| `showoff/` | War-map UI (served by kernel) |
| `brain/` | Craft / bar_brain weights |
| `story/` | Proxy story exports |

See `../docs/DEPLOY_TRUTH.md`.
